# 📘 Aoanki: Elegant Anki Deck Management


### Aoanki (青暗记) is a lightweight and expressive library designed to manage, manipulate, and export Anki decks with clarity and ease.
### Inspired by the beauty of structured learning and minimalistic tools, Aoanki empowers learners and creators to craft intelligent flashcard workflows.

## ✨ Features
- 📂 Deck Composition — Define and structure decks with simple, declarative logic
- 🔄 Template Handling — Easily manage card templates and styling
- 🧠 Note Generation — Automate note creation using clean, extensible data sources
- 🛠️ Export Ready — Seamlessly export .apkg files for immediate use in Anki
- 🧾 Readable by Design — Human-readable configs; ideal for version control and collaboration

## 🔍 Use Cases
#### Build decks programmatically for language learning, medicine, law, or any field
#### Keep card data in sync with external sources (e.g., CSV, JSON, or APIs)
#### Version and share curated learning decks with others via Git
